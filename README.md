# Rotary District 4195 website prototype

This is a split static project structure for the Rotary District 4195 website.

## Structure
- index.html: public overview homepage
- pages/: internal detail pages
- assets/css/: shared styles
- assets/js/: shared behavior for theme toggle and mobile navigation
- assets/images/: branding and imagery
- data/: placeholder JSON files for future directory/event population

## Suggested next work
1. Populate leadership.json with real district officers.
2. Expand clubs.json with the district directory.
3. Replace placeholder copy with approved district copy in Spanish or bilingual format.
4. Add imagery and real event data.
